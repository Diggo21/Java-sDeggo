# 🧙‍♂️ Laboratório de Magia

> *"Onde bugs viram features e testes viram feitiços"*

## 📜 Sobre este Laboratório

Bem-vindo ao **Laboratório de Magia** — uma pasta de testes criativa onde o código ganha vida própria!

### 🎭 Conceito

Cada arquivo de teste aqui é um **feitiço**. Cada execução é um **ritual**. E cada bug corrigido é uma **vitória mágica**.

### 📁 Conteúdo

| Arquivo | Tipo de Magia | Descrição |
|---------|---------------|-----------|
| `GrimorioDeTestes.java` | Feitiço Principal | O grimório mestre que executa todos os rituais de teste |

### 🚀 Como Executar os Feitiços

```bash
# Navegue até o laboratório
cd laboratorio-de-magia

# Compile o grimório
javac GrimorioDeTestes.java

# Execute a magia
java GrimorioDeTestes
```

### 🧙‍♀️ Regras do Laboratório

1. **Sem `System.out.println` sem propósito** — cada print deve contar uma história
2. **Variáveis têm alma** — nomeie-as com carinho
3. **Loops são poções** — cuide da proporção dos ingredientes
4. **Erros são portais** — cada exception ensina um novo feitiço
